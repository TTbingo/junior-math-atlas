# 初中数学知识图谱

按初中数学的三大知识领域——**代数、几何、统计与概率**——组织站点。每个知识点回答三件事：**这个结论为什么成立**、**它对应课本的哪一节**、**遇到题该按什么顺序想**。

- 内容规模：3 大领域 / 12 主题 / **61 个知识点全部成稿** / 65 张配图
- 教材定位：逐篇对应**人教版（2024 版）义务教育教科书·数学**的册次、章、节
- 纯静态、零依赖：断网双击 `dist/index.html` 可完整浏览（KaTeX 已本地化）

## 三大领域

| 领域 | 主题 | 主题数 | 知识点数 |
|------|------|--------|----------|
| 代数 | 数与式、方程与不等式、函数 | 3 | 20 |
| 几何 | 图形的初步认识、三角形、四边形、圆、相似与投影、图形与变换、锐角三角函数 | 7 | 33 |
| 统计与概率 | 统计、概率 | 2 | 8 |

## 每个知识点的十一个板块

| 板块 | 内容 |
|---|---|
| 说明 | 概念是什么、定义里每个条件为什么必要 |
| 使用场景 | 这个知识在生活与中考里怎么用 |
| 注意点 | 最容易忽略的边界条件 |
| **教材定位** | 册次 · 第X章 章名 · X.Y 节名 + 与教材的对应关系及差异 |
| **证明** | 每条一个「结论 N + 推理过程 + 关键一步」 |
| 解题思路 | 拿到题目先想什么、按什么顺序推 |
| 按场景的例题 | 3 道起，每题场景不重复，答案逐题验算 |
| 常用推论 | 由本节结论能直接推出的结论 |
| 易错点 | 「错在哪 / 为什么错 / 正确做法」三段对照 |
| 直观理解 | 图示或类比，帮助形成直觉 |
| **关联知识点** | 分**前置 / 后续 / 常一起考**三类，每类带关系说明 |

## 目录结构

```
content/
  modules.json       3 领域 / 12 主题 / 61 知识点清单（唯一定义，学习顺序=字典序）
  points/*.json      61 篇知识点正文
  media/*.svg        65 张配图与领域脉络图
  taxonomy.json      板块定义、领域、核心素养、场景枚举、禁用词
  textbook.json      人教版（2024 版）六册 34 章目录，用于教材定位校验
  standards.json     课标条目库
  site.json          站名与副标题
assets/              CSS / JS / 本地化 KaTeX
templates/           HTML 模板
build.py             单文件构建脚本（仅 Python 标准库）
tools/               配图生成、内容体检、审计与批量脚本
dist/                构建产物（不入库，走 gh-pages 分支）
```

## 本地使用

```bash
python build.py                        # 构建 dist/
python build.py --check                # 只校验：死链、裸公式、禁用词、板块齐全
MATH_NO_CLEAN=1 python build.py        # 原地覆盖，不整树删 dist
python tools/check_content.py          # 内容体检（教材定位、前置顺序、关联三类、概念超前）
python tools/audit_site.py             # 结构与引用审计
python tools/gen_geo_figs.py           # 重画几何配图
```

## 内容规范（写新篇目前必读）

1. `sections` 是**字典**，十一个键齐全；`why.steps` 每条是 `{conclusion, proof, key}`——结论、推理、关键一步。
2. **前置不再单设字段**：前置写在 `related` 里并标 `kind: "前置"`，`prerequisites` 由它派生。两处维护必然漂移。
3. `related` 每条 `{id, kind, note}`，`kind` 只能是 `前置 / 后续 / 常一起考`，三类每类至少一条。
   - 前置 = 学本文之前必须先会的；后续 = 学完接着用本文成果的；常一起考 = 中考常同题出现的。
4. **每篇必须有 `textbook_ref`**，精确到节。note 只讲对应关系与差异，不复制定位行。
   教材未单列的内容（尺规作图、中位线、梯形、将军饮马、隐圆、统计推断）要定位到它依赖的知识点并说明。
5. 例题 3 道以上，场景取自 `taxonomy.scenes` 且同页不重复；每题 `solution` 写完整算式，`answer` 给结论。
6. **正文禁止出现裸知识点 ID**（如 `m2-05-02`）：用 `[[m2-05-02]]` 标记，渲染层自动转成带链接的知识点名称。
7. 禁用跳步话术：`显然`、`易证`、`不难看出`（初中允许写「证明」，但理由链要完整）。
8. SVG 是 XML：文本中的 `<`、`>` 必须写成 `&lt;`、`&gt;`；图文尺寸要与 `media` 里的 `width/height` 一致。
9. 领域脉络图的 `viewBox` 宽度固定 760，内置文字不小于 12px——图会被缩放到内容栏宽度显示。
