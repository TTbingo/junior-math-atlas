# 初中数学知识图谱

按初中数学的三大知识模块——**代数、几何、统计与概率**——组织站点。每个知识点回答两件事：**这个结论为什么成立**，**遇到题该按什么顺序想**。

- 内容规模：3 大领域 / 12 主题 / 45 知识点（当前已成稿 4 篇，清单内其余为待写）
- 知识脉络：依据资料库《初中数学思维导图》的十一章脉络，重组为领域 → 主题 → 知识点
- 内容与题型参照：《中考冲刺专题突破·数学》(2024)
- 纯静态、零依赖：断网双击 `dist/index.html` 可完整浏览（KaTeX 已本地化）

## 三大领域

| 领域 | 内容 | 主题数 | 知识点数 |
|------|------|--------|----------|
| 代数 | 数与式、方程与不等式、函数 | 3 | 15 |
| 几何 | 图形的初步认识、三角形、四边形、圆、相似与投影、图形与变换、锐角三角函数 | 7 | 23 |
| 统计与概率 | 统计、概率 | 2 | 7 |

每个领域首页顶部有一张**知识脉络图**，标出该领域的主题顺序与主题内的知识点；每个知识点固定十个板块：说明 · 使用场景 · 注意点 · **原理：为什么成立** · **解题思路** · 按场景的例题 · 常用推论 · 易错点 · 直观理解 · 关联知识点。

## 目录结构

```
content/
  modules.json       3 领域 / 12 主题 / 45 知识点清单 + 知识点中文名（唯一定义）
  points/*.json      知识点正文（按清单逐篇补写）
  media/*.svg        配图与领域脉络图
  taxonomy.json      板块定义、领域、核心素养、场景枚举、禁用词
  site.json          站名与副标题
assets/              CSS / JS / 本地化 KaTeX
templates/           HTML 模板
tools/restructure.py    重建领域体系（改清单时运行，会覆盖 modules.json）
tools/check_content.py  内容体检：前置顺序、前置≠关联、场景重复、跳步话术、公式配对
build.py             单文件构建脚本（仅 Python 标准库）
dist/                构建产物（不入库）
```

## 本地使用

```bash
python tools/restructure.py            # 重建 modules/taxonomy/site 的领域体系
python build.py                        # 构建 dist/
python build.py --check                # 只校验：死链、裸公式、禁用词、十板块
python tools/check_content.py          # 内容体检（前置与关联的语义规则）
MATH_NO_CLEAN=1 python build.py        # 原地覆盖，不整树删 dist
```

## 内容规范（写新篇目前必读）

1. `sections` 是**字典**，十个键齐全；`why` 必须有 `steps`（≥2 步）与 `experiment`。
2. `prerequisites` 只放**真正的先修知识**，且必须在清单中排在本文之前；**不得与 `related` 重复**（小学站 87 条前置错误的根因就是拿 `related[0]` 顶替前置）。
3. `related` 每条 `{id, note}` 单向书写，构建时自动生成反向分组；两向都写会重复（渲染层已去重兜底）。
4. 例题 3 道以上，场景取自 `taxonomy.scenes` 且同页不重复；每题的 `solution` 必须写完整算式，`answer` 给结论。
5. 禁用跳步话术：`显然`、`易证`、`不难看出`（初中允许写「证明」，但理由链要完整）。
6. SVG 是 XML：文本中的 `<`、`>` 必须写成 `&lt;`、`&gt;`；图文尺寸要与 `media` 里的 `width/height` 一致。
7. 领域脉络图的 `viewBox` 宽度固定 760，内置文字不小于 12px——图会被缩放到内容栏宽度显示。
