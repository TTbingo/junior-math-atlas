# 初中数学专题图谱

按《中考冲刺专题突破·数学》(2024) 的**三部分**组织初中数学：先夯实考点，再炼模型，最后冲满分。每个知识点回答两件事——**这个结论为什么成立**，**遇到题该按什么顺序想**。

- 内容规模：3 部分 / 24 主题 / 87 知识点（当前已成稿 3 篇，清单内其余为待写）
- 纯静态、零依赖：断网双击 `dist/index.html` 可完整浏览（KaTeX 已本地化）

## 三部分

| 模块 | 内容 | 主题数 | 知识点数 |
|------|------|--------|----------|
| 第一部分 · 玩转基础 | 中考全部考点：数与式、方程与不等式、函数、三角形与四边形、相似、圆、图形变换、统计与概率 | 8 | 31 |
| 第二部分 · 专题专练 | 全等/相似的辅助线模型、圆与最值、图形变换、函数综合、应用题与创新 | 7 | 31 |
| 第三部分 · 满分突破 | 压轴专题：图形变换、最值与定值、隐形圆、存在性、双曲线与抛物线、新定义 | 9 | 25 |

每个知识点固定十个板块：说明 · 使用场景 · 注意点 · **原理：为什么成立** · **解题思路** · 按场景的例题 · 常用推论 · 易错点 · 直观理解 · 关联知识点。

## 目录结构

```
content/
  modules.json       3 部分 / 24 主题 / 87 知识点清单（唯一定义）
  points/*.json      知识点正文（按清单逐篇补写）
  media/*.svg        配图
  taxonomy.json      板块定义、领域、核心素养、场景枚举、禁用词
  site.json          站名与副标题
assets/              CSS / JS / 本地化 KaTeX
templates/           HTML 模板
tools/scaffold.py    生成清单与字典（改体系时运行）
tools/check_content.py  内容体检：前置顺序、前置≠关联、场景重复、跳步话术、公式配对
build.py             单文件构建脚本（仅 Python 标准库）
dist/                构建产物（不入库）
```

## 本地使用

```bash
python tools/scaffold.py               # 重新生成 modules/taxonomy/site/standards
python build.py                        # 构建 dist/
python build.py --check                # 只校验：死链、裸公式、禁用词、十板块
python tools/check_content.py          # 内容体检（前置与关联的语义规则）
MATH_NO_CLEAN=1 python build.py        # 原地覆盖，不整树删 dist
```

## 内容规范（写新篇目前必读）

1. `sections` 是**字典**，十个键齐全；`why` 必须有 `steps`（≥2 步）与 `experiment`。
2. `prerequisites` 只放**真正的先修知识**，且必须在清单中排在本文之前；**不得与 `related` 重复**（上次小学站 87 条前置错误的根因就是拿 `related[0]` 顶替前置）。
3. `related` 每条 `{id, note}` 单向书写，构建时自动生成反向分组；两向都写会重复（渲染层已去重兜底）。
4. 例题 3 道以上，场景取自 `taxonomy.scenes` 且同页不重复；每题的 `solution` 必须写完整算式，`answer` 给结论。
5. 禁用跳步话术：`显然`、`易证`、`不难看出`（初中允许写「证明」，但理由链要完整）。
6. SVG 是 XML：文本中的 `<`、`>` 必须写成 `&lt;`、`&gt;`；图文尺寸要与 `media` 里的 `width/height` 一致。
